# 测测你的理想恋爱剧本

解压整个 ZIP 后，用浏览器打开 `index.html`。项目使用原生 HTML、CSS 和 JavaScript，可在离线状态下运行。浏览器允许使用本地存储时，可以从上次答到的位置继续，也可以查看上次完成的结果。

## 题目和结果

40 道题分为五幕，每道题有四个选项。每个选项为安稳感、共鸣感、新鲜感、浪漫感、空间感、成长感中的一个维度计一分。各维度的分数是选中次数除以可选次数，同分时比较最后一幕中的比例，仍同分时取最后一次选中的并列维度。结果页可以保存 900 × 1200 像素的 PNG 分享卡。

六种结果分别是细水长流、灵魂共鸣、即兴远行、心动收藏家、各自有风和并肩进化论。测试内容用于娱乐和自我探索。

## 文件

- `index.html` 页面结构
- `styles.css` 视觉样式与响应式布局
- `questions.js` 五幕题库和计分维度
- `stories.js` 六种结果文案和卡片配色
- `app.js` 答题、计分、本地进度和分享卡生成
- `moonlit-cover.jpg` 原创封面，由内置图像生成工具制作
